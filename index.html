/ 02 — CAPABILITIES

Всё для управления
серверной инфраструктурой.

Не перегруженная панель, а понятный инструмент администратора — от первой установки до ежедневного обслуживания.

01

Установка серверов

Vanilla, Paper, Purpur и Fabric. Выбор версии Minecraft, Java, памяти и порта. Безопасная установка во временную директорию.

VANILLAPAPERPURPURFABRIC
02

Автосоздание мира

Сервер сам создаёт мир и server.properties. IlandyMC определяет доступные настройки по фактической версии.

Только поддерживаемые параметры
03

Редактор настроек

Логические, числовые и текстовые значения. Описания параметров, маскировка секретов и сохранение неизвестных ключей.

04

CLI и TUI

Управляй серверами командами или через интерактивный интерфейс прямо в терминале. Без отдельного графического приложения.

ilandyily
05

Процессы и systemd

Start, Stop, Restart, Status и логи. Использование systemd, если сервис установлен, или встроенного менеджера процессов.

06

Резервные копии

Архивы с SHA-256, проверка целостности и безопасное восстановление без перезаписи существующего сервера.

Защита от опасных путей в архиве
07

Безопасность

Проверки PID, HTTPS, права 0600 для RCON-секретов, ограничения systemd и безопасная работа с архивами.

08

Обновления и диагностика

Проверка релизов IlandyMC, контроль SHA-256 пакета и диагностика ОС, CPU, RAM, диска и systemd.

/ 03 — WORKFLOW

Сначала проверка.
Потом — установка.

IlandyMC не предполагает, какие настройки должны быть у сервера. Он запускает выбранное ядро, ждёт создания конфигурации и показывает только реально существующие параметры.

/ 04 — COMMAND LINE

Терминал — твоя панель.

Все основные операции доступны через команду ilandy. TUI запускается короткой командой ily.

01ilandy installУстановка
02ilandy statusСостояние
03ilandy logsЛоги
04ilandy backupРезервная копия
05ilandy doctorДиагностика
06ilandy self-updateОбновление
TERMINAL / BASHEXAMPLE

# Установить сервер Paper

$ ilandy install

# Проверить состояние сервера

$ ilandy status survival

# Создать резервную копию

$ ilandy backup survival

SECURITY NOTE

Безопасность — не опция.

Не открывай RCON и управляющие порты в публичный интернет. online-mode=false отключает штатную проверку аккаунтов Minecraft: для такого сценария нужен корректно настроенный прокси с авторизацией, например Velocity.

/ 05 — PROJECT DETAILS

Честно о возможностях.

IlandyMC 1.0.0 — стабильная функциональная база. Некоторые функции пока не входят в релиз.

Входит в 1.0.0

  • Установка Vanilla, Paper, Purpur, Fabric
  • Управление процессами и systemd
  • Редактор server.properties
  • Резервное копирование и восстановление
  • CLI, TUI, диагностика и обновление
  • Русский и английский языки

Пока не реализовано

  • Forge и NeoForge
  • Веб-панель и многосерверная панель
  • Автоустановка плагинов и модов
  • Планировщик и очистка старых бэкапов
  • Обновление Minecraft JAR и rollback
  • Автоматическое управление firewall
